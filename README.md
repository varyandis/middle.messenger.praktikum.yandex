# 💬 Webchat

**Webchat** — учебный проект мессенджера, реализованный как **SPA** (Single Page Application) без серверного рендеринга.
Интерфейс построен на собственном компонентном подходе с базовым классом `Block` и событийной системой `EventBus`.

Проект написан на **TypeScript**, собирается с помощью **Vite** и развёрнут на **Netlify**.

## 📄 Страницы и маршруты

Приложение использует собственный клиентский роутер с поддержкой **History API** и навигации назад/вперёд.
Поддерживается обновление страницы (F5) на любом маршруте благодаря настройке Netlify redirects.

| Страница             | Маршрут                      |
| -------------------- | ---------------------------- |
| Вход                 | `/`                          |
| Регистрация          | `/sign-up`                   |
| Чаты                 | `/messenger`                 |
| Профиль пользователя | `/settings`                  |
| Изменить данные      | `/settings/edit`             |
| Изменить пароль      | `/settings/password`         |
| Ошибка 404           | любой несуществующий маршрут |
| Ошибка 500           | `/500`                       |

## 🧠 Архитектура

* **Block** — базовый класс для компонентов и страниц
* **EventBus** — система событий и жизненного цикла компонентов:

  * `init`
  * `componentDidMount`
  * `componentDidUpdate`
  * `componentDidHide`
* Компонентный подход без сторонних UI-библиотек
* Разделение логики, шаблонов и стилей по страницам
* Собственный клиентский роутер

## 🌐 HTTP и WebSocket

### HTTP API

* Собственный класс **HTTPTransport** на базе `XMLHttpRequest`
* Поддержка:

  * `GET`, `POST`, `PUT`, `DELETE`
  * JSON и `FormData`
  * query-параметров
  * обработки ошибок
* Интеграция с API Яндекс.Практикума:

  * авторизация
  * регистрация
  * работа с профилем
  * чаты и пользователи

### WebSocket

* Реализован **real-time чат**
* Подключение по токену чата
* Получение истории сообщений
* Отправка и получение сообщений в реальном времени
* Корректное закрытие WebSocket при уходе со страницы
* Хранение сообщений в Store (`messagesByChat`)

## 🔐 Безопасность

* Защита от **XSS**:

  * пользовательский ввод рендерится только через `{{ }}` Handlebars
  * не используется `{{{ }}}`
  * отсутствует вставка пользовательских данных напрямую через `innerHTML`
* Простая проверка авторизации в роутере:

  * неавторизованный пользователь перенаправляется на `/`
